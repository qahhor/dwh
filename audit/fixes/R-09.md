# R-09 — Детерминированный release promotion и rollback

## Решение

Создать release workflow: tag -> build once -> SBOM/sign -> publish immutable digests -> approval -> migrations -> deploy -> health/smoke -> record evidence. Rollback использует предыдущий digest, не rebuild.

## Затрагиваемые файлы

- новый `.github/workflows/release.yml`
- `scripts/prod/deploy.*`
- `scripts/prod/restore.*`
- `deploy/compose/*.yml`
- release/runbook documentation

## Последовательность

```text
signed tag -> immutable artifacts -> staging -> approval -> production
failure -> previous digest -> schema compatibility check -> smoke
```

## Валидация

- [ ] Нельзя deploy без explicit version/digest.
- [ ] Migration failure не запускает web process.
- [ ] Intentional failed rollout откатывается.
- [ ] Release evidence содержит commit, SBOM и health result.
