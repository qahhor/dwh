# R-09 — Обновить и классифицировать CI dependency toolchain

## Наблюдение и риск

Remote run `33833803385` предупреждает, что Node 20 actions принудительно
запускаются на Node 24. Workflows всё ещё используют `actions/checkout` и
`actions/setup-java` v4, закреплённые полными SHA. `npm ci` также сообщил об
одной moderate issue, но production-only `npm audit` не завершился в окно
проверки, поэтому затронутый package и runtime/dev scope не подтверждены.

## Минимальный план

Отдельным dependency PR перейти на официальные Node 24-compatible action
releases и воспроизводимо получить/классифицировать npm advisory. Каждый
`uses:` оставить pinned на full commit SHA; не смешивать это с изменением
product code.

## Критерий закрытия

- [ ] Все обновлённые actions опубликованы официальными owners.
- [ ] `scripts/release/verify-release.ps1` и `actionlint` проходят.
- [ ] Backend/frontend/security/E2E/release jobs зелёные.
- [ ] Remote annotations больше не содержат Node 20 deprecation warning.
- [ ] Moderate npm finding имеет package, scope, fix/acceptance decision, owner и expiry.
