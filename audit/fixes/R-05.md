# R-05 — Доказать совместное восстановление DB и objects

## Наблюдение и риск

Backup image, `age`, SHA-256 и restore scripts реализованы, но в репозитории нет
актуального evidence изолированного восстановления БД вместе с object bytes.
Database-only restore не восстанавливает файлы пользователя.

Evidence: `scripts/prod/backup.ps1`, `scripts/prod/restore.ps1`,
`deploy/images/backup/backup-loop.sh`, `docs/ops/production-launch-checklist.md`.

## Минимальный план

1. Создать disposable dataset с DB records и файлами известных checksums.
2. Выполнить encrypted backup и независимую копию/версионирование object store.
3. Восстановить в изолированное окружение, затем проверить схему, права,
   representative records и byte-for-byte objects.

## Критерий закрытия

- [ ] Проверены encrypted archive checksum и отдельно хранимая age identity.
- [ ] DB migration gate и smoke проходят после restore.
- [ ] Object checksums совпадают, search rebuild завершается.
- [ ] Зафиксированы фактические RPO/RTO и результат владельца.
