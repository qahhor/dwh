# R-05 — Расширение E2E по существующим модулям

## Решение

Не добавлять новые функции. Для уже существующих files, RBAC, settings, audit и analytics добавить по одному критическому role-aware journey. Добавить keyboard и automated accessibility smoke. Chromium оставить PR baseline; второй browser — nightly или release gate.

## Затрагиваемые файлы

- `e2e/playwright.config.ts`
- `e2e/tests/browser/instance/`
- `e2e/package.json`
- `.github/workflows/ci.yml`

## Матрица

```text
module x principal x critical journey x error state
```

## Валидация

- [ ] Все существующие principal modules имеют минимум один journey.
- [ ] Проверяются loading, empty, error и denied states.
- [ ] Keyboard focus и accessible names входят в assertions.
- [ ] Failure artifacts не содержат credentials.
