# R-04 — Coverage baseline и thresholds

## Решение

Подключить JaCoCo для Maven reactor и coverage output Angular test runner. Первый этап — только измерение и публикация baseline; второй — diff coverage и минимумы для критических packages.

## Затрагиваемые файлы

- `pom.xml`
- `.github/workflows/ci.yml`
- `apps/web-instance/angular.json`
- `apps/web-cp/angular.json`
- test configuration обеих SPA

## Пороговая модель

```text
global baseline: не ниже зафиксированного значения
changed lines: высокий diff coverage
auth/audit/rbac/migrations: отдельный branch threshold
```

## Валидация

- [ ] Backend и frontend reports публикуются в CI.
- [ ] Generated code исключён одинаково локально и в CI.
- [ ] Непокрытая новая ветвь нарушает diff threshold.
- [ ] Threshold не стимулирует бессмысленные mock-only tests.
