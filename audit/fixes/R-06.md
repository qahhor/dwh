# R-06 — Immutable supply-chain pins

## Решение

Закрепить GitHub Actions на commit SHA, а build/runtime/production images — на digest с человекочитаемым tag в комментарии. Обновления делать отдельными автоматическими PR.

## Затрагиваемые файлы

- `.github/workflows/ci.yml`
- `Dockerfile`
- `apps/web-instance/Dockerfile`
- `apps/web-cp/Dockerfile`
- `docker-compose.yml`
- `deploy/compose/*.yml`

## Пример

```text
uses: actions/checkout@<commit-sha> # v4.x
image: postgres:18-alpine@sha256:<digest>
```

## Валидация

- [ ] Один commit всегда резолвит одинаковые digests.
- [ ] SBOM содержит точные версии base layers.
- [ ] Update PR проходит backend/frontend/E2E/security.
- [ ] Нет `latest` или floating production tags.
