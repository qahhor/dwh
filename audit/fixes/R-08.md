# R-08 — Явный one-instance runtime invariant

## Решение

До появления утверждённого HA SLO закрепить один instance process на клиента в deployment policy и startup metadata. Не вводить Redis только ради гипотетического масштаба. При переходе к HA выделить rate-limit и notification bus за интерфейсы.

## Затрагиваемые файлы

- `deploy/compose/*.yml`
- Nomad job templates/policies
- `RateLimitService` documentation/tests
- `MsSseRegistry` documentation/tests
- ADR deployment model

## Псевдокод

```text
assert desiredReplicas == 1 while stateMode == LOCAL
future: RateLimitStore + RealtimeBus adapters
```

## Валидация

- [ ] Deployment validation отклоняет replicas > 1.
- [ ] Health/info endpoint показывает local-state mode.
- [ ] Runbook описывает consequence и recovery.
- [ ] Distributed design начинается только после SLO decision.
