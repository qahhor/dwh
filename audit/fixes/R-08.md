# R-08 — Ввести coverage baseline и changed-lines gate

## Наблюдение и риск

CI запускает backend, frontend и E2E tests, но JaCoCo/LCOV report, baseline и
changed-lines threshold не найдены. Test count сам по себе не защищает новые
ветви критической логики.

Evidence: `pom.xml`, `.github/workflows/ci.yml`, `apps/web/package.json`.

## Минимальный план

1. Подключить JaCoCo и Vitest coverage; сначала только публиковать baseline.
2. Исключения generated/config code зафиксировать одинаково локально и в CI.
3. После устойчивого baseline включить diff threshold для auth, RBAC, files,
   audit, idempotency и migrations; global threshold повышать постепенно.

## Критерий закрытия

- [ ] Backend/frontend reports публикуются на каждый CI run.
- [ ] Baseline привязан к main SHA и не снижается без review.
- [ ] Непокрытая changed branch в критическом package блокирует PR.
- [ ] Integration/E2E tests не заменяются mock-only coverage.
