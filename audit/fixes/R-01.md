# R-01 — Восстановить зелёный remote CI baseline

## Наблюдение и риск

Remote run `33833803385` для `main`/`1b24d3f` завершился ошибкой в
`release-config` и `security`. Пока полный workflow не зелёный на точном SHA,
release evidence не является воспроизводимым.

## Локально реализованный минимальный fix

- `scripts/prod/test-backup-status.ps1` проверяет status через Docker volume от
  production UID/GID 10001 и не зависит от Linux host ownership.
- `pom.xml` закрепляет patched Tomcat 11.0.25 для `core`, `el`, `websocket`.
- `.github/workflows/ci.yml` сканирует разрешённый backend SBOM, web и E2E dev
  dependencies без ослабления HIGH/CRITICAL gate.
