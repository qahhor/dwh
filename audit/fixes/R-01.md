# R-01 — Production fail-fast для Typesense key

## Решение

Разделить dev и production defaults. В общем `application.yml` не должно быть известного ключа. Dev-профиль может задавать локальный ключ; production profile обязан валидировать непустое значение и отклонять placeholder.

## Затрагиваемые файлы

- `apps/instance/src/main/java/com/greenwhite/dwh/instance/search/typesense/TypesenseProperties.java`
- `apps/instance/src/main/resources/application.yml`
- новый/существующий production profile
- `deploy/compose/docker-compose.fleet.prod.yml`
- тест конфигурации startup

## Псевдокод

```text
if production && (apiKey blank || apiKey == knownDevKey):
    fail startup with configuration error
compose: ${TYPESENSE_API_KEY:?required}
```

## Валидация

- [ ] Production без ключа не стартует.
- [ ] Production с placeholder не стартует.
- [ ] Dev Compose по-прежнему стартует локально.
- [ ] App и Typesense получают один ephemeral key.
- [ ] Ключ не появляется в логах или artifacts.
