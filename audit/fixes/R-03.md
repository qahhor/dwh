# R-03 — Frontend unit tests как CI gate

## Решение

В frontend job после каждого `npm ci` запускать `npm test`, затем production build. Сохранять test report при failure.

## Затрагиваемые файлы

- `.github/workflows/ci.yml`
- при необходимости Angular test reporter configuration

## Команды

```text
cd apps/web-instance && npm ci && npm test && npm run build
cd apps/web-cp && npm ci && npm test && npm run build
```

## Валидация

- [ ] Сломанный unit test блокирует frontend job.
- [ ] Обе SPA запускают тесты в headless mode.
- [ ] Failure report доступен как artifact.
- [ ] Build запускается только после зелёных тестов.
