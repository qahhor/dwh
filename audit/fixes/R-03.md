# R-03 — Закрыть privacy, retention и DSAR ownership

## Наблюдение и риск

Классы PII описаны, но заполненное решение конкретной установки по
controller/processor, legal basis, retention и delete/export/hold не найдено.
Код не может заменить это организационное решение.

Evidence: `docs/security/threat-model.md`, `docs/technical-specification.md`
(`NFR-DATA-05`, `AC-12`).

## Минимальный план

1. Заполнить installation annex для каждого PII/data class.
2. Назначить legal, security и operational owners.
3. Проверить delete/export по PostgreSQL, Typesense, object storage и правилам
   backup retention/legal hold.

## Критерий закрытия

- [ ] Annex утверждён и не содержит `TBD`.
- [ ] Есть проверяемая процедура DSAR/delete/export/hold.
- [ ] Тест фиксирует результаты во всех хранилищах без публикации PII.
- [ ] Backup и audit retention согласованы с политикой установки.
