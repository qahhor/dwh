# R-10 — Единый источник release readiness

## Решение

Создать одну актуальную release-readiness matrix. Исторические аудиты остаются неизменными, но получают явную пометку `Superseded by ...`. README и release process ссылаются только на текущую матрицу.

## Затрагиваемые файлы

- `README.md`
- `REPORT.md`
- `docs/audit/AUDIT-03-production-readiness.md`
- `docs/audit/AUDIT-05-production-readiness-final.md`
- `docs/audit/AUDIT-06-m3-auth-review.md`
- новый актуальный release checklist

## Минимальная схема

```text
requirement | status | evidence | owner | last_verified | expires | release_gate
```

## Валидация

- [ ] Одновременно существует только один current readiness verdict.
- [ ] M3 exponential delay остаётся open до кода и теста.
- [ ] README test counts генерируются или обновляются проверяемо.
- [ ] Pilot и GA имеют разные, явные критерии.
