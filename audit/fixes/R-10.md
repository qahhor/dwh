# R-10 — Сделать one-server invariant проверяемым

## Наблюдение и риск

`RateLimitService` и `MsSseRegistry` хранят state в памяти процесса. Документация
ограничивает базовую поставку single-host топологией, но machine-readable
запрета на запуск нескольких server replicas не найдено.

## Минимальный план

1. Явно описать `stateMode=LOCAL` и `supportedServerReplicas=1` в system info и
   deployment validation.
2. Добавить contract test, отклоняющий поддерживаемую конфигурацию `server > 1`.
3. Не вводить Redis/message bus до отдельного HA/SLO решения; будущие adapters
   проектировать за интерфейсами rate-limit store и realtime bus.

## Критерий закрытия

- [ ] Runbook объясняет эффект accidental scale-out и recovery.
- [ ] Deployment contract фиксирует одну server replica.
- [ ] System info/diagnostics показывает local state mode.
- [ ] Multi-node режим не заявляется поддерживаемым без отдельного ADR и tests.
