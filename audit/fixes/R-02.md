# R-02 — Утвердить performance SLO и профиль нагрузки

## Наблюдение и риск

ТЗ фиксирует объём 500 registered/100 active users и 50 ГБ upload/month, но не
задаёт утверждённые p95/p99/error/saturation thresholds и распределение по
установкам. Без них load test не имеет pass/fail критерия.

Evidence: `docs/technical-specification.md` (`NFR-PERF-01`, `NFR-PERF-02`,
`AC-12`), `docs/ops/production-launch-checklist.md`.

## Минимальный план

1. Product + Operations утверждают workload mix, dataset и числовые thresholds.
2. Команда выполняет load + soak на том же image digest и host profile, что
   используется для acceptance.
3. Evidence содержит p50/p95/p99, error rate, DB/JVM/host saturation и решение
   владельца SLO.

## Критерий закрытия

- [ ] Installation annex содержит workload distribution, SLO и owner.
- [ ] Сценарий и dataset воспроизводимы без customer secrets/PII.
- [ ] Release image проходит load и soak по утверждённым порогам.
- [ ] Результат привязан к commit и image digest.
