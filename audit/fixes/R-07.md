# R-07 — Декомпозировать frontend mega-components

## Наблюдение и риск

`TasksComponent` содержит 3136 строк, users — 1579, roles — 1354. Это не повод
для переписывания SPA, но такая концентрация UI, state и orchestration повышает
стоимость исправлений и риск регрессий.

## Минимальный план

Начать с `apps/web/src/app/features/tasks/tasks.component.ts`: по одному
выделять toolbar/filter, list, detail, comments/files и editor в typed
presentational components. HTTP/state orchestration оставить за feature facade.

## Критерий закрытия

- [ ] Routes, permissions и API contracts не изменены.
- [ ] Каждый извлечённый блок имеет focused component test.
- [ ] Playwright critical journeys остаются зелёными.
- [ ] Нет дублирования design tokens, loading/error/empty handling.
- [ ] Изменения выпускаются небольшими reviewable slices.
