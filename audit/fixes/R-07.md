# R-07 — Автоматизация dependency currency

## Решение

Настроить Dependabot или Renovate для Maven, npm, Docker и GitHub Actions. Группировать patch/minor updates, major upgrades выпускать отдельно с migration notes.

## Затрагиваемые файлы

- новый `.github/dependabot.yml` или `renovate.json`
- package manifests/locks по PR бота
- Docker/Compose pins

## Политика

```text
weekly patch/minor groups
separate security PRs
major upgrades require ADR/compatibility check
never auto-merge around red gates
```

## Валидация

- [ ] Создан PR для тестового patch update.
- [ ] Typesense/nginx upgrade проходит contract и E2E tests.
- [ ] Security PR имеет короткий SLA.
- [ ] Игнорирования имеют owner и expiry.
