# Security audit — 2026-08-31

## Вердикт

Release security gate: **FAIL**. В текущем workspace есть три прямых unauthenticated attack path и один authorization/data-scope bypass. Пока они не отключены или не исправлены с negative tests, релиз недопустим.

## Минимальная threat model

| Trust boundary | Активы | Основные угрозы |
|---|---|---|
| Internet → nginx → APIs | сессии, RBAC, tenant data | auth bypass, CSRF, injection, IDOR, brute force |
| Instance → Control Plane | license/fleet/module status | spoofed callback, replay, privilege escalation |
| Instance → внешние URL | webhook secrets, network | SSRF, DNS rebinding, data exfiltration |
| Browser → rendered user content | session/user actions | stored XSS, unsafe URL schemes |
| DB/Typesense/backups/logs | email, phone, IP, UA, audit history | leakage, excessive retention, unencrypted backup |
| CI → registry/deployment | source, tokens, artifacts | dependency/action tampering, mutable images |

## Защитные механизмы, которые подтверждены

- Server-side permission annotations/interceptor и secure defaults: `RequiresPermissionInterceptor.java`, `SecurityConfig.java`.
- Argon2/password hashing, `SecureRandom` tokens и hash-at-rest для сессий: `KauthPasswordHasher.java`, `KauthAuthService.java`.
- CSRF double-submit для cookie auth, typed API errors: `SecurityConfig.java`, `GlobalExceptionHandler.java:34-164`.
- Parameterized JDBC SQL и Flyway migrations; audit immutability migration `V014__audit_log_immutable.sql`.
- Upload limits, quota, extension denylist, path normalization, attachment disposition: `MfFileService.java:21-63,190-197`; `MfFileController.java:89-93`. Content sniffing/AV не найдено.

## OWASP coverage conclusion

- Injection: параметризованный SQL снижает риск; dynamic module JSON/URL validation требует усиления.
- Broken access control: **не пройдено** из-за search/callback.
- Authentication failures: **не пройдено** из-за SSO.
- XSS: **не пройдено** из-за markdown renderer.
- SSRF: **не пройдено** для webhooks.
- CSRF/security headers: backend имеет базу, но frontend CSP не найден.
