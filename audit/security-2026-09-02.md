## OWASP coverage status

- AuthN/AuthZ, CSRF, IDOR/search, markdown XSS and audit controls have server or
  regression coverage; the formerly unverified SSO/custom-module paths remain
  disabled by migrations V018/V019.
- SSRF: webhook boundary hardened as above; S3 endpoint remains operator-trusted
  configuration, not untrusted user input.
- Injection: repositories use parameterized access in inspected critical paths;
  no claim is made for every query without a dedicated SAST/dataflow report.
- Secrets/supply chain: local scans are green; runtime uses pinned base digests
  and non-root/read-only constraints. Remote release artifact is still missing.
