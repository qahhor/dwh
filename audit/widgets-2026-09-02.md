# UI/UX audit — 2026-09-02

## Critical-flow status

The unified product has one navigation shell and local administration pages;
there is no supported Control Panel route/runtime. Browser verification passed
login, roles, users, tasks, files, notifications, announcements and System on a
clean database. The notification page's former frontend/backend contract drift
was corrected to `/notifications/inbox`, `/unread-count` and inbox read actions
(`notification.service.ts:37-74`, `MsNotificationController.java:22-64`).
