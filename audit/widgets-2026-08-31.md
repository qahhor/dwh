## Критические пользовательские потоки

1. Login/session/SSO — password login имеет состояния ошибок, но SSO функционально небезопасен и должен быть скрыт до исправления.
2. Task/project action — есть один E2E, но нет системной проверки loading/empty/permission/error.
3. IAM users/roles/data scope — UI tests красные, а search нарушает server scope; визуальная правка не заменяет backend authorization.
4. File upload/download — компонент и backend tests есть, browser flow отсутствует.
5. CP fleet/module moderation — основной fleet flow частично E2E; module callback нельзя выпускать.

## Не подтверждено

- WCAG conformance level, screen-reader matrix и результаты axe для authenticated pages не найдены.
- Product analytics/funnel data для onboarding/friction не найдено; поэтому оценки конверсии не делаются.
- Design-system source of truth отсутствует: ADR-0012 описывает направление, но нет отдельного versioned package/tokens contract, согласованного между apps.
