## Release test pyramid

- **Per commit/PR:** backend unit/integration/ArchUnit, frontend unit/typecheck/
  build, config/docs, Gitleaks/Trivy, 9+ Chromium E2E, upload boundaries and
  cross-role API negatives.
- **Nightly:** Firefox/WebKit, accessibility scan, dependency scan with cached
  DB, migration from oldest supported version, 60-minute load smoke.
- **Release candidate:** clean install, upgrade, failed migration, rollback,
  EICAR/scanner outage, target edge scan, 4-hour load soak and isolated restore.
- **Final target:** 24-hour soak and operator-executed backup/restore/alert drill.

## Test quality metrics

- PR flaky retry rate <1%; quarantined tests = 0 at release.
- 100% of P0/P1 defects receive a regression test.
- Critical-role authorization matrix coverage = 100% of supported operations.
- Release evidence is bound to commit, image digest, environment profile and
  timestamp; screenshots/logs contain no secrets/PII.
- Failed security/restore/performance gate cannot be waived without owner,
  expiry, mitigation and explicit go/no-go sign-off.
