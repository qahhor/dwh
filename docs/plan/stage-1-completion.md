# Статус Этапа 1 (Stage 1: Core Monolith & CMS)

**Дата ревизии:** 2026-08-28
**Ветка:** `main`
**Статус:** **В работе — фаза ремедиации (R).** Прежняя оценка «Завершено на 100%» отозвана
по итогам AUDIT-02: критерием готовности является матрица результатов ТЗ-01 разд. 8.2,
по ней демонстрируемы ~6 из 20 результатов.

## Что реализовано (проверено фактически)

- **Бэкенд instance** — модульный монолит (md, kauth, ms, mf, audit, kwh, search):
  Argon2id, cookie-сессии (HttpOnly/Secure/Lax), API-токены, OTP-модель, задачи/проекты
  с инвариантом I-T1, уведомления + transactional outbox (`SKIP LOCKED`), файлы с SHA-256-
  дедупликацией, вебхуки с HMAC-SHA256, динамические поля (jsonb + GIN), поиск pg_trgm,
  идемпотентность, RFC 9457, keyset-пагинация.
- **Control plane** — клиенты, лицензии, heartbeat (базово).
- **Фронтенд** — Angular 22.1.4, standalone + signals, дизайн-токены, Command Palette,
  модули Auth/Профиль/Пользователи/Роли/Задачи/Уведомления.
- **Тесты** — ArchUnit (границы модулей), Flyway integrity, 8 юнит-классов.

## Что НЕ готово (см. AUDIT-02, план ремедиации)

- 🔴 Версии вне поддержки (Boot 3.4.3 / Java 23 / PG 16) — R1
- 🔴 Spring Security и CSRF отсутствуют — R2 · Rate limiting отсутствует — R3
- 🔴 Миграции при старте приложения (регресс A-4) — R4 · CI отсутствует — R5
- 🟠 Vault, Nomad-деплой, наблюдаемость — фаза P
- 🟠 SSE, реальные каналы доставки, лицензии Transit, кольца — фаза F
- 🟠 Интеграционное тестовое покрытие RBAC — R6
