# Памятка агенту: что читать, как работать, как отчитаться

**Актуализировано:** 2026-10-21

**Статус:** справочный контекст для AI-ассистентов; не нормативный источник. Правила — в [AGENTS.md](../AGENTS.md).

## Что читать

- Сначала: `AGENTS.md` и `docs/ai-context.md` §7 (текущая точка, ≤ 3 КБ). Остальные разделы handoff — по необходимости.
- ADR — не целиком: `grep -n "^## " docs/adr/ADR-NNNN-*.md`, затем нужный раздел через `sed -n`.
- Архивы `docs/history/*` — только `grep` по коду шага, ADR или дате; целиком не открывать.
- Вопрос по коду: `py -m graphify query "<вопрос>"` до того, как открывать много файлов.
- Файл больше 100 КБ — смотреть размер и заголовки, не читать целиком.

## Как работать

- Всё идёт прямо в `main`: без веток и worktree; пишет один агент, остальные читают.
- Тяжёлые проверки (полный `verify`, e2e, ZAP, Testcontainers) — по одной; перед запуском занять замок `.tools/tmp/heavy.lock`
  (файл с именем агента и временем), после — удалить. Занятый замок — ждать, не обходить.
- Пока разрабатываете — только целевые тесты (`-pl <модуль> -Dtest=...`, затронутые веб-спеки). Один полный прогон — на
  финальных коммитах перед пушем (AGENTS.md §5).
- E2E: брать готовый стенд из `scripts/dev/test-e2e.ps1`; логи шардов писать в файл и разбирать `grep`/`tail`; не
  запускать e2e на чужом стенде и не останавливать чужие стенды (порты, тома, контейнеры другого агента не трогать).
- Секреты, токены, пароли и персональные данные не печатать и не коммитить.

## Дисциплина вывода

- Ограничивать вывод команд (`| tail -n 40`, `| head`, `grep -c`); логи и транскрипты целиком не печатать.
- Для прогонов гейтов писать краткий итоговый файл (команда, результат, число упавших) и ссылаться на него.
- Не опрашивать фоновую работу по кругу: дождаться уведомления о завершении.
- Финальный отчёт — не больше 40 строк: что сделано, коммиты, результаты проверок, открытые риски.

## Почему так (факты)

- Этапные агенты до введения правил тратили 660–870 тыс. токенов на задачу; исправляющие агенты Sonnet 2026-10-21 — 140–170 тыс.
- Один раздел §7 handoff весил около 35 тыс. токенов, и его читал каждый агент; теперь история в архиве, §7 короткий.
