# ADR-0012: UI-фундамент фронтенда

**Статус:** Принято (2026-08-27)
**Дата:** 2026-08-27
**Зависит от:** ADR-0002 (Angular 22), ТЗ-02 (UI/UX)

---

## 1. Контекст

Направление задано CEO: **корпоративный сегмент, минималистичный дизайн**. Нужен фундамент
компонентов: строить всё своё, взять готовую библиотеку «как есть» или гибрид. Решение надо
зафиксировать до первой строки фронтенда — смена библиотеки после M1 означает переписывание
всех экранов. Дизайнера в команде нет (senior-разработчики) — дизайн-система должна жить в коде.

## 2. Решение

**Angular Material + CDK со строгой собственной темой на дизайн-токенах.**
Материал даёт поведение и доступность; внешний вид — полностью наш, через токены ТЗ-02.

| Вариант | Плюсы | Минусы | Вердикт |
|---|---|---|---|
| **Angular Material + CDK, своя тема** | A11y и клавиатура из коробки; официальная поддержка в такт версиям Angular; M3-токены темизируются полностью; CDK (overlay, table, a11y, drag) — лучший низкоуровневый слой | Риск «выглядит как Google» — гасится строгой темой и запретом дефолтных стилей | **Да** |
| PrimeNG | Много готовых сложных виджетов (таблицы, деревья) | Тяжёлый собственный стиль, темизация против течения; качество a11y неровное; минимализм труднее | Нет |
| Полностью свой кит на CDK | Максимум контроля | Месяцы на то, что Material даёт бесплатно (a11y, фокус-менеджмент); без дизайнера — риск самопала | Нет |
| Tailwind + headless | Гибко | Ещё одна парадигма стилей в команде без фронтенд-избытка; a11y — на нас | Нет |

## 3. Правила использования (обязательные)

1. **Токены — единственный источник стиля.** Все цвета/типографика/отступы — CSS-переменные
   из ТЗ-02 §3; прямые hex/px в компонентах запрещены (проверка stylelint в CI).
2. **Дефолтная тема Material не используется** — только наша, собранная из токенов.
3. **Один способ на задачу:** таблица — CDK Table (наша обёртка `ui-grid`), диалог — наш
   `ui-dialog` поверх CDK Overlay и т.д. Компонентный зоопарк запрещён: новые обёртки — через
   ревью владельца UI-кита.
4. **Living styleguide:** страница `/ui-kit` в приложении со всеми обёртками и токенами —
   собирается всегда, служит приёмкой дизайна (Storybook — опционально позже).
5. Иконки — один набор: **Material Symbols (outlined)**, вес и размер из токенов.
6. Шрифт — **Inter** (self-hosted, без CDN — экземпляры могут жить в закрытых контурах),
   с системным фолбэком; кириллица и латиница из коробки.

## 4. Последствия

- Скорость: M1-экраны строятся на готовом поведении, дизайн — темизация, не разработка.
- Обновления Angular несут обновления Material — уже учтено политикой версий ADR-0002.
- Расход: обёртки `ui-*` — это ~неделя в M1 сверх голого Material; окупается единообразием.
- Риск «материального» вида принят и гасится правилами 1–2; контроль — по `/ui-kit` странице.

## 5. Действия

1. [ ] M1: тема из токенов ТЗ-02, обёртки `ui-button/ui-grid/ui-dialog/ui-form-field`, страница `/ui-kit`.
2. [ ] stylelint-правило «только токены» в CI.
3. [ ] Self-hosted Inter + Material Symbols в сборке.
