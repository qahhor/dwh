# Обзор SmartupCMS на одной странице

**Актуализировано:** 2026-10-21

**Статус:** справочный обзор, не нормативный источник. Требования — [ТЗ](../technical-specification.md), решения — [ADR](../README.md#authority-tier-2--current-decisions).

## Что это

SmartupCMS — self-hosted low-code CMS для разработчиков: сущность объявляется один раз на сервере, а платформа строит список,
форму, карточку, историю, экспорт, массовые действия, пункт меню и коды прав. Одна установка — одна организация. Интерфейс на ru,
uz и en. Продукт до релиза 1.0.

## Репозиторий

| Папка | Что внутри |
|---|---|
| `apps/server` | модульный монолит Spring Boot: бизнес-модули, runtime платформы, миграции Flyway |
| `apps/web` | веб-клиент Angular |
| `libs` | `platform-api` (публичный контракт для внешних модулей), `platform-common`, `core-types`, `provider-spi`, `platform-testkit` |
| `tools` | `cms-cli` (генератор модулей и сущностей), `api-types` (типы из OpenAPI) |
| `e2e` | Playwright: e2e и доступность |
| `deploy` | Compose, Ansible, образы, наблюдаемость, приёмка |
| `examples`, `modules` | внешний модуль-пример; каталог `/app/modules` для JAR внешних модулей |

## Модули сервера

Размер — класс по числу строк Java (оценка на 2026-10-21): S < 1 тыс., M 1–3 тыс., L 3–7 тыс., XL > 7 тыс. Подробнее —
[карта модулей](module-map.md).

| Модуль | Назначение | Размер |
|---|---|---|
| `common` | runtime сущностей (`EntityDefinition`), запросы, формулы, ошибки, JDBC, отчётный движок | XL |
| `config` | сборка приложения, безопасность, демо-данные | L |
| `md` | мастер-данные: IAM (пользователи, роли, права), оргструктура, настройки, языки, динамические поля, меню, реестр модулей, контракты живых форм, отчёты и дашборды | XL |
| `studio` | живые формы без deploy, версии, формулы, документы, автоматизации, пакеты решений, шаблоны | XL |
| `kauth` | вход, сессии, API-токены, сброс пароля | M |
| `ms.task`, `ms.note`, `ms.notify` | задачи и проекты, заметки (эталон low-code), оповещения и outbox | M, S, M |
| `mf` | файлы: загрузка, антивирус, хранение на диске или в S3 | M |
| `audit` | журнал изменений и событий безопасности | M |
| `report` | выгрузки и импорт xlsx, рассылки отчётов | L |
| `search` | полнотекстовый поиск (Typesense) | L |
| `upl` | загрузки данных, разбор, проверка, витрины для отчётов | L |
| `warehouse` | вторая база (pg-dwh): raw-слой, витрины `mart.rows` | M |
| `webhook` | исходящие вебхуки с подписью HMAC | S |
| `jobs`, `units`, `analytics`, `example` | очередь заданий; единицы измерения; показатели дашборда; эталонные модули cookbook | M, S, S, S |

## Части low-code платформы

- **Runtime `EntityDefinition`** — объявление сущности на сервере порождает CRUD, права, историю и экран ([ADR-0019](../adr/ADR-0019-low-code-entity-model.md)).
- **Живые формы Studio** — администратор создаёт справочники и документы без deploy: версии схемы, формулы, строки документа ([ADR-0038](../adr/ADR-0038-live-simple-forms.md), [ADR-0041](../adr/ADR-0041-live-form-evolution.md)).
- **Отчёты и аналитика** — наборы данных, дашборды, рассылки ([ADR-0036](../adr/ADR-0036-shared-reports-and-dashboards.md), [ADR-0044](../adr/ADR-0044-report-analytics.md), [ADR-0045](../adr/ADR-0045-report-mailings.md)).
- **Автоматизации «если–то»** ([ADR-0046](../adr/ADR-0046-live-form-automations.md)).
- **Пакеты решений и шаблоны** — перенос между установками ([ADR-0047](../adr/ADR-0047-solution-packages-and-templates.md)).
- **Витрины хранилища** — загрузки `upl` публикуют данные в pg-dwh как источник отчётов ([ADR-0048](../adr/ADR-0048-warehouse-mart-reports.md)).

## Хранилища данных

- **PostgreSQL (OLTP)** — основная база приложения, миграции Flyway.
- **pg-dwh** — вторая база хранилища: raw-слой и витрины отчётов; свои миграции (`MigrateMain`).
- **Typesense** — производный поисковый индекс; можно пересобрать из PostgreSQL.
