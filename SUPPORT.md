# SmartupCMS Support

## Community support

Community support is best effort. Use a GitHub issue for a reproducible defect
or a scoped enhancement proposal, after searching existing issues. Include the
SmartupCMS version, deployment method, relevant sanitized logs, and exact
reproduction steps. Never post credentials, personal data, database dumps, or
private customer URLs.

The community does not guarantee response or resolution times. Questions about
custom deployments should include enough configuration detail to reproduce the
problem without exposing secrets.

## Security and conduct

- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
- Report community conduct incidents according to
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Commercial support

Smartup may offer managed hosting, deployment, upgrades, backup operations,
incident response, and contractual SLAs. Commercial support does not change the
features or license of the public product. A public commercial contact channel
has not yet been documented in this repository; until it is published, no
commercial SLA should be inferred from community support.
